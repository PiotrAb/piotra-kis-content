## Projekt zaliczeniowy

Projekt zaliczeniowy może być wykonany w dowolnej bibliotece frontendowej poznanej w trakcie zajęć.

Możesz korzystać z dowolnych bibliotek pomocniczych, które znajdziesz w repozytorium NPM oraz w serwisie GitHub. Dodatkowo pamiętaj, aby przy budowie UI zastosować jakąś gotową bibliotekę (np. Bootstrap, Tailwind CSS lub Prime).

Ocenie podlegać będzie poprawność implementacji, zgodność ze standardami oraz zgodność z urządzeniami o różnych rozdzielczościach ekranu (RWD).

### Aplikacja pogodowa
Zaimplementuj kompletny frontend dla aplikacji pogodowej, pozwalającej na wyświetlanie pogody na aktualny dzień oraz na najbliższy tydzień. Wykorzystaj dowolne API pogodowe (np. [OpenWeather](https://openweathermap.org), [Open-Meteo](https://open-meteo.com) itp.).
Dodatkowo zadbaj, aby użytkownik mógł wybrać lokalizację. Aby ustalić swoją lokalizację możesz skorzystać z [Geolocation API](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation_API) a aby zamienić lokalizację na konkretny adres z Reverse Geocoding API (np. [Geiapify](https://www.geoapify.com/tools/reverse-geocoding-online/)).

### Frontend do dowolnego API z DummyJSON

Zaimplementuj frontend do dowolnego API dostępnego w ramach [DummyJSON](https://dummyjson.com).

Możesz na przykład zbudować sklep z koszykiem lub blog z możliwością dodawania komentarzy.

### Blog programisty wykorzystujący składnię markdown

Wykorzystując bibliotekę Gatsby, Next.js, Hugo lub Nuxt.js zaimplementuj serwis WWW, będący blogiem programisty. Funkcjonalność ma obejmować możliwość czytania wpisów z bloga, czytanie komentarzy i formularz do ich dodawania (nie muszą być one zapisywane).
