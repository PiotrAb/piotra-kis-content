## Repozytoria

## Informacje

Przedmiot **Współczesny front-end aplikacji internetowych - HTML, CSS i JavaScript** przeznaczony jest dla słuchaczy PSPiZK.

Laboratorium w semestrze zimowym 2022/23 zakładają 20h spotkań.

## Zaliczenie

Zaliczenie odbywa się na podstawie indywidualnego projektu realizowanego przez Słuchaczy na koniec zajęć. Projekt obejmuje wiedzę z zakresu HTML5, CSS i Java Script

**Projekt zaliczeniowy**

Przygotuj aplikację będącą frontendem dla jednego z wybranych przez Ciebie API. Wykorzystaj jedno z API dostępnych na [tym repozytorium](https://github.com/public-apis/public-apis). 

Aplikacja musi być stworzona z wykorzystaniem HTML5, CSS3 i JavaScript (ES6+). Przy wykonaniu projektu nie wolno korzystać z zewnętrznych frameworków do budowy frontendu aplikacji internetowych, ale wykorzystać można popularne frameworki do budowania GUI (np. Bootstrap).

Aplikacja stworzona musi być zgodnie z zasadami budowy aplikacji przedstawionymi na zajęciach.
