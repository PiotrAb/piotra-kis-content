## Aktualna lista zadań do samodzielnego wykonania

Lista zadań do samodzielnego wykonania aktualizowana jest z zajęć na zajęcia (dodawane są nowe zadania). Proszę pamiętać - nie trzeba wykonać wszystkich zadań, aby otrzymać ocenę bardzo dobrą z kursu.

Z zadań można otrzymać max. 100 pkt. dlatego przy ich wyborze proszę kierować się zarówno swoimi preferencjami jak i punktacją.

Aby ułatwić śledzenie listy zadań - zamieszczam odnośnik do aplikacji Word na platformie Office365 - dostęp do niej możliwy jest po zalogowaniu się do platformy z wykorzystaniem konta w domenie @o365.umk.pl lub @o365.stud.umk.pl.

[Zadania do samodzielnego wykonania](https://umkt-my.sharepoint.com/:w:/g/personal/piotra_o365_umk_pl/EQ6vLZZFazZHt98uMR-9-44Blh2AlqfByQEioN8u_CIofA?e=oRBlnR)

Wyniki swojej pracy proszę zamieszczać w sforkowanym przez siebie repozytorium [Java22L-zadania](https://github.com/IS-UMK/Java22L-zadania). Repozytorium zawiera jedynie katalogi z pustym plikiem README.md. Proszę w sforkowanych repozytoriach zamieszczać swoje rozwiązania zadań i po skończonej pracy wysyłać na główne repozytorium pull request'a - będzie to dla mnie znak, że chcą Państwo rozliczyć konkretne zadania i znacznie ułatwi mi to organizację sprawdzania Państwa kodów. 

Po sprawdzeniu zadania pull request'y będę zamykał i przesyłał informację zwrotną w komentarzu. Nie będę merge'ował Państwa pull request'ów z głównym repozytorium.

Aby zsynchronizować swojego fork'a z głównym repozytorium proszę wewnątrz katalogu ze swoim fork'iem wydać następujące polecenia:

    git remote add upstream https://github.com/IS-UMK/Java22L-zadania.git
    git fetch upstream
    git checkout master
    git merge upstream/master
    git push 

Pierwszą komendę należy wydać tylko za pierwszym razem.
