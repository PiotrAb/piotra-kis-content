Zajęcia z przedmiotu *Kurs komputerowy Java* odbywają się w każdy czwartek w godzinach 8:00 - 9:30 oraz w każdy piątek w godzinach 14:00 - 15:30 w pracowni PK COK.

W semestrze letnim roku akademickiego 2021/22 kurs odbywa się w pełni stacjonarnie.

Materiały do zajęć są na bieżąco aktualizowane - bazują na wcześniejszych edycjach kursu, lecz ulegają ciągłej ewolucji. Materiały video nie są aktualizowane (pochodzą z czasu, gdy zajęcia odbywały się w trybie zdalnym lub hybrydowym).

## Tematyka zajęć

Kurs to 30h zajęć stacjonarnych, na których poruszane będą następujące tematy:

+ wstęp do języka Java - składnia
+ programowanie obiektowe w języku Java
+ dziedziczenie w języku Java
+ współbieżność w języku Java
+ graficzne interfejsy użytkownika: AWT, Swing i JavaFX
+ programowanie zorientowane sieciowo
+ aplikacje webowe - frameworki Java Spark i Spring

Jeśli starczy nam czasu, to dodatkowo zajmiemy się następującą tematyką:

+ tworzenie aplikacji mobilnych w języku Java dla systemu Android
+ zewnętrzne biblioteki i nowoczesny język Java

## Zasady zaliczenia przedmiotu

Na ocenę końcową z zajęć składają się:

+ praca nad zadaniami do zajęć (do zdobycia max. 100pkt., ***50% wkładu do oceny końcowej***)
+ wykonanie projektu zaliczeniowego (do zdobycia max. 100pkt., ***50% wkładu do oceny końcowej***)

Jak widać - do zaliczenia wystarczy uzyskanie maksymalnej liczby punktów z zadań lub wykonanie projektu. Aby uzyskać ocenę lepszą niż dostateczna należy wykonać zarówno zadania jak i projekt, aby zdobyć większą liczbę punktów. Ostateczna ocena wystawiona zostanie na podstawie następującej skali:

+ [100; 90] pkt. - 5.0
+ [80; 89] pkt. - 4.5
+ [70; 79] pkt. - 4.0
+ [60; 69] pkt. - 3.5
+ [50; 59] pkt. - 3.0
+ [0; 49] pkt. - 2.0

Ostateczna punktacja to oczywiście 0.5 * punktacja z zadań + 0.5 * punktacja z projektu zaliczeniowego.

W ramach kursu dostępnych będzie kilkanaście zadań z pośród których wybrać można jedynie te, które będą interesujące - każde zadanie ma przydzieloną swoją punktację zależną od stopnia trudności i złożoności, a co za tym idzie nakładu pracy, który należy włożyć w jego rozwiązanie.

Projekt zaliczeniowy oceniony zostanie na dwóch płaszczyznach - zdobyć będzie można max. ***80 pkt. za techniczny aspekt projektu*** i max. ***20 pkt. za "obronę" projektu*** - "obrona" to nic innego jak udzielenie odpowiedzi na pytania dotyczące projektu oraz jego prezentacja.

Listę zadań jak i listę projektów zaliczeniowych znaleźć można w zakładce ***Materiały do zajęć*** (lista zadań jest na bieżąco aktualizowana, a projekty ogłoszone zostaną w połowie semestru). 

***UWAGA!*** Zachęcam do zgłaszania swoich własnych propozycji związanych z projektem - mogą Państwo zaproponować coś związanego z zainteresowaniami, realizowaną pracą inżynierską lub po prostu temat, który będzie Państwu odpowiadał - zawsze łatwiej pracować nad czymś potencjalnie ciekawym niż przygotowywać kolejną aplikację jakich pełno znaleźć można w sieci.
