# Wiadomości ogólne

Laboratoria ze Wstępu do Data Mining obywają się w każdy czwartek w godzinach 16:00 - 17:30 w pracowni PK1. Laboratoria to łącznie 20h spotkań.

W ramach zajęć poruszane będą następujące tematy:
+ co to jest data mining i jakie narzędzia wykorzystuje? (1h)
+ podstawowe elementy języka Python (1h)
+ biblioteki NumPy, pandas i Matplotlib (1h)
+ wstępna obróbka danych (1h)
+ regresja (2h)
+ klasyfikacja (2h)
+ klasteryzacja (2h)
+ detekcja anomalii (2h)
+ redukcja wymiarowości danych (2h)
+ rozpoznawanie twarzy i pisma odręcznego (2h)
+ eksploracja danych tekstowych (2h)

# Zasady zaliczenia przedmiotu

Na ocenę końcową składają się:

+ samodzielna praca (wykonywanie zadań do tematów)
+ projekt zaliczeniowy

Z poszczególnych części podlegających ocenie otrzymać można:

+ 50 pkt. za pracę samodzielną
+ 50 pkt. za projekt zaliczeniowy

Ostateczna ocena otrzymana z zajęć będzie wystawiona na podstawie sumy zebranych punktów.

Zależności pomiędzy punktacją a ocenami są następujące: 

+ [100; 90] pkt. - 5.0
+ [80; 89] pkt. - 4.5
+ [70; 79] pkt. - 4.0
+ [60; 69] pkt. - 3.5
+ [50; 59] pkt. - 3.0
+ [0; 49] pkt. - 2.0

Nie trzeba wykonywać wszystkich zadań i projektu - proszę samodzielnie zdecydować, w jaki sposób uzbieracie Państwo punkty na ocenę końcową.
